HARD RULES (the page fails review if any is broken)
  - Use only lp-* classes that appear in @lepidus-design.md. Never invent a
    class, element or modifier. Copy the canonical anatomy from §5 exactly —
    nesting, wrapper elements, label spans, chevron SVGs and all.
  - Link the stylesheet and script exactly like this, nothing else:
      <link rel="stylesheet" href="https://lepide-design-system.vercel.app/v1/lepidus.css">
      <script src="https://lepide-design-system.vercel.app/v1/lepidus.js" defer></script>
  - Set data-theme="light" on <html>; themes are switched only by changing
    that attribute. Never write per-theme colours by hand.
  - No hardcoded colours, spacing, radii or font sizes anywhere (no hex, rgb,
    px values for those). Page-level layout CSS (centering the card, the
    top-right switcher position, max-width) uses var(--space-*),
    var(--color-background-*), var(--color-border-*), var(--radius-*),
    var(--typography-*) tokens from the token appendix in @lepidus-design.md.
    Only use token names that exist there; never guess a name and add a hex
    fallback.
  - Page CSS must never target .lp-* selectors. Widths come from the
    documented modifiers (e.g. lp-button--full-width, lp-input--full-width,
    lp-dropdown--full-width), label placement from lp-input__row--label-top.
  - Do not write click/keyboard handlers for parts lepidus.js owns
    (.lp-dropdown__trigger, .lp-dropdown__option, [data-lp-modal-open], tabs,
    accordion, stepper). Your only JS: the form submit validation and the
    theme switch via the lp-dropdown-change event.
  - Exactly one label per field, inside the component (lp-input__label); no
    external <label for>. No custom ".field" wrappers around components.
  - Keep the documented accessibility markup: aria-invalid + aria-describedby
    on invalid inputs, role/aria attributes exactly as in the contract,
    visible focus left to the system styles, a <main> landmark, lang on <html>.
  - If you need a component the contract marks "React-only", stop and tell
    me instead of hand-building it.
